# タスク管理アプリ

直感的に使えるタスク・案件・KPI 管理ツール（1ファイル静的Webアプリ）。

## 機能

- **今日**: 今日やる・マイボール・相手待ち・打合せを一覧
- **タスク**: 5ステータス（🔴 マイボール / 🟡 相手待ち / 🔵 早くやりたい / 💡 アイディア / ✓ 完了）でフィルタ
- **案件**: スケジュールバー（期間 + 進捗 + 今日マーカー）/ 進捗 vs 期待 vs 遅れ％
- **KPI**: 現在値 / 目標値 / 期待値（期間経過率）/ 遅れ％、遅れの大きい順で表示
- **打合せリマインド**: 朝開いて差し込みタグ付きテンプレで催促文・打合せリマインド文を自動生成 → コピー/メーラー
- **催促リマインド**: 「相手ボール」かつ期日到来 → 催促文を自動提案
- **Googleカレンダー連携**: GAS Web アプリ経由で予定を自動取込

## 構成

```
task-app/
├── index.html      # アプリ本体（1ファイル完結）
├── gas/
│   └── Code.gs    # Googleカレンダー連携用 GAS スクリプト
└── README.md
```

## デプロイ

GitHub Pages を有効化すると、`https://<user>.github.io/<repo>/` で公開されます。

## Googleカレンダー連携の設定

1. https://script.google.com/ で新規プロジェクト作成
2. `gas/Code.gs` の内容を貼り付け
3. [デプロイ] → [新しいデプロイ] → 種類「ウェブアプリ」
   - 実行ユーザー: 自分
   - アクセスできるユーザー: 自分のみ
4. デプロイ後のURLを、アプリの ⚙ 設定 → 「GAS URL」に貼り付け
5. 「📅 今すぐ取り込む」または「起動時に自動同期」で同期

## データ

- ブラウザの **LocalStorage** に保存（端末ごと）
- ⚙ 設定 → エクスポート/インポート でバックアップ可能
